PDFKit Local

Junte, extraia e gire páginas de PDF sem enviar o arquivo para lugar nenhum. Tudo acontece neste navegador.

    Privacidade

    Os arquivos são lidos e processados localmente pelo navegador, com a biblioteca pdf-lib. Esta versão não possui upload nem coleta de dados dos documentos, e essa regra deve valer nas próximas versões. Não prometemos anonimato absoluto nem segurança perfeita, e PDFs protegidos por senha não são suportados.

    Para quem é

    Estudantes, profissionais administrativos, pequenos negócios, professores, freelancers e qualquer pessoa que precise organizar PDFs sem instalar um programa.

    Executar o projeto

    Requer Node.js 18 ou superior. Stack: TypeScript, Vite, pdf-lib, HTML e CSS.

    npm install
npm run dev

npm run build
npm run preview
